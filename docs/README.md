# docs — внутренняя кухня

Эта папка **не публикуется**: она добавлена в `exclude` в `_config.yml`,
поэтому Jekyll её не собирает и на сайт она не попадает.

Здесь лежит всё, что нужно только вам и мне при работе над сайтом:
инструкции, концепты, идеи, заметки по архитектуре. В публичных
markdown-файлах (`README.md`, статьи) этого быть не должно.
