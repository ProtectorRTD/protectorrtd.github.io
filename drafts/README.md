# Черновики

Папка в `exclude` в `_config.yml` — Jekyll её не собирает, на сайт ничего отсюда не попадает.

Пишите здесь незаконченное в любом виде. Когда статья готова — переносите файл
в `articles/ru/` или `articles/en/` и проверяйте, что в front matter есть `title`.

Если не хотите, чтобы черновики уходили на GitHub, раскомментируйте `drafts/` в `.gitignore`.
