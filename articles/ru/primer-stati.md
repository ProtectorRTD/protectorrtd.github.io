## Как добавить новую статью

1. Скопируйте этот файл в `articles/ru/` под новым именем, например `nastroika-routera.md`.
2. Поменяйте в шапке (front matter) `title`, `date` и `description`.
3. Пишите текст в Markdown ниже.
4. `git add . && git commit -m "новая статья" && git push` — GitHub Pages соберёт сайт сам.

Статья автоматически появится в списке на главной странице в разделе
«Статьи на русском». Сортировка — по полю `date`, новые сверху.

## Что можно использовать

Обычное форматирование Markdown: **жирный**, *курсив*, `код`, [ссылки](https://github.com/ProtectorRTD).

```js
console.log('Подсветка синтаксиса работает');
```
